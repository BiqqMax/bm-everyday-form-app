# Contributing

Thank you for your interest in contributing to Everyday Forms! This project is open source, and contributions are welcome from anyone.

## How to contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes, then commit with a clear message.
4. Open a pull request describing the problem and your solution.

## What is helpful

- Bug reports and reproduction steps
- Feature suggestions and improvements
- Documentation updates

## Current focus

The current focus is wiring the Resend API for submission emails. Contributions that help implement, test, or document email delivery for form submissions are especially valuable.

## Notes

- Keep the code style consistent with the existing app.
- Add tests or validations where appropriate.
- If you are unsure, open an issue first and ask.
